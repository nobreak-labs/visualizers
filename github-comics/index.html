          6화

          깃 명령어는 AI가 대신 쳐 줘요

          우리는 "무엇을 하고 싶은지"만 말해요. AI가 알맞은 깃 명령을 실행하고, 무슨 일을 했는지 설명해 줘요. 아래 말풍선을 눌러 보세요.

          정리

          용어 한 장 정리

          처음엔 비유로 기억하면 충분해요.

          repository (저장소)
          프로젝트 폴더 + 모든 변경 기록코드·문서·설정 파일이 함께 사는 집
          commit (커밋)
          게임 세이브 포인트"무엇을 바꿨는지" 메시지와 함께 저장
          push / pull
          올리기 / 내려받기내 컴퓨터와 깃허브를 맞추는 일
          branch (브랜치)
          main에서 갈라진 복사본 갈래망쳐도 main은 안전
          issue (이슈)
          할 일과 문제를 적는 게시판 글"README 실행 명령 오타 수정"
          pull request (PR)
          "내 브랜치를 main에 합쳐도 될까요?" 요청서합치기 전에 동료가 검사해요
          review (리뷰)
          동료의 검사와 의견승인(Approve)하면 합칠 준비 완료
          merge (머지)
          갈래를 main에 합치기PR의 마지막 버튼
          conflict (충돌)
          같은 줄을 서로 다르게 고친 상태사람이 어느 쪽으로 할지 고르면 끝

          깃허브는 혼자 잘하려는 도구가 아니라, 같이 잘하려는 도구예요.
