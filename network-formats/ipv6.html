IPv6 고정 헤더

필드 이름과 역할
필드풀네임크기설명
VersionInternet Protocol Version4 bitsIPv6에서는 값이 6입니다.
Traffic ClassTraffic Class1 B · 8 bits상위 6비트는 DSCP, 하위 2비트는 ECN입니다.
  • DSCP 0 — 기본 전달
  • DSCP 46 — EF — 신속 전달
  • ECN 0 / 1 / 2 / 3 — Not-ECT / ECT(1) / ECT(0) / CE
Flow LabelFlow Label20 bits출발지 주소·목적지 주소와 함께 같은 흐름에 속한 패킷을 식별합니다. 0은 흐름 라벨이 지정되지 않았음을 뜻합니다.
Payload LengthPayload Length2 B · 16 bits고정 헤더를 제외한 길이로, 확장 헤더도 포함합니다. 점보그램은 0과 Jumbo Payload 옵션을 사용합니다.
Next HeaderNext Header1 B · 8 bits바로 뒤의 확장 헤더 또는 상위 프로토콜을 식별합니다.
  • 0 — Hop-by-Hop Options
  • 6 — TCP
  • 17 — UDP
  • 43 — Routing
  • 44 — Fragment
  • 50 — ESP
  • 58 — ICMPv6
  • 59 — No Next Header
  • 60 — Destination Options
Hop LimitHop Limit1 B · 8 bits라우터가 전달할 때 1씩 감소하는 홉 한도입니다. 전달하려는 패킷의 값이 0이거나 감소 후 0이 되면 폐기합니다.
Source AddressSource IPv6 Address16 B · 128 bits송신자의 16바이트 IPv6 주소입니다.
Destination AddressDestination IPv6 Address16 B · 128 bits목적지의 16바이트 IPv6 주소입니다.
Extension HeadersExtension Headers가변 길이고정 헤더와 상위 계층 사이의 선택적 확장 헤더입니다. Next Header 필드로 연결되며 유형마다 구조가 다릅니다.
DataUpper-layer Payload가변 길이TCP, UDP, ICMPv6 등의 메시지입니다. IPv6 고정 헤더 자체에는 체크섬이 없습니다.
