BOOTP Message

BOOTP의 고정 필드와 주소, 큰 필드 및 확장 영역을 살펴보세요.

APPLICATION LAYER

BOOTP 메시지 형식

한 행 32비트 · 비트 / 바이트 오프셋
필드 이름과 역할
필드풀네임크기설명
opOperation1 B · 8 bitsBOOTP 요청과 응답을 구분합니다.
  • 1 — BOOTREQUEST — 클라이언트 요청
  • 2 — BOOTREPLY — 서버 응답
htypeHardware Type1 B · 8 bits하드웨어 주소 유형입니다. 이 도표는 Ethernet 기준입니다.
  • 1 — Ethernet
hlenHardware Address Length1 B · 8 bits하드웨어 주소 길이(바이트)입니다. Ethernet MAC 주소는 6입니다.
hopsRelay Hop Count1 B · 8 bits클라이언트는 0으로 시작하며 중계 에이전트가 전달할 때 증가시킵니다.
xidTransaction Identifier4 B · 32 bits클라이언트 요청과 서버 응답을 대응시키는 거래 식별자입니다.
secsSeconds Elapsed2 B · 16 bits클라이언트가 부팅을 시도하기 시작한 뒤 경과한 초입니다.
unusedUnused2 B · 16 bitsRFC951의 BOOTP 기본 형식에서는 0으로 채우는 미사용 영역입니다. 후속 확장은 이 위치에 Broadcast 플래그를 정의합니다.
ciaddrClient IP Address4 B · 32 bits이미 알고 있는 클라이언트 IPv4 주소입니다.
yiaddrYour IP Address4 B · 32 bits서버가 클라이언트에게 제공하는 IPv4 주소입니다.
siaddrServer IP Address4 B · 32 bitsRFC951에서는 BOOTREPLY를 보내는 서버가 자신의 IPv4 주소를 담습니다. 후속 BOOTP·DHCP 규격에서는 부트스트랩에 사용할 서버 주소로 설명합니다.
giaddrRelay Agent IP Address4 B · 32 bits중계 에이전트의 IPv4 주소입니다.
chaddrClient Hardware Address16 B · 128 bits클라이언트의 하드웨어 주소를 담는 16바이트 영역입니다. Ethernet에서는 앞 6바이트가 MAC 주소입니다.
snameServer Host Name64 B · 512 bits선택적 서버 호스트 이름을 담는 고정 64바이트 영역입니다. 문자열은 NUL로 종료합니다.
fileBoot File Name128 B · 1024 bits부팅 파일 이름을 담는 고정 128바이트 영역입니다. 문자열은 NUL로 종료합니다.
vendVendor-specific Area64 B · 512 bits공급업체 확장 정보를 담는 영역입니다. RFC1048 형식에서는 앞 4바이트 Magic Cookie 뒤에 옵션을 담습니다.
