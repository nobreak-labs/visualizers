ICMP 헤더

한 행 32비트 · 비트 / 바이트 오프셋
필드 이름과 역할
필드풀네임크기설명
TypeMessage Type1 B · 8 bits메시지 유형입니다. 주요 값은 다음과 같습니다.
  • 0 — Echo Reply
  • 3 — Destination Unreachable
  • 5 — Redirect
  • 8 — Echo Request
  • 11 — Time Exceeded
  • 12 — Parameter Problem
CodeMessage Code1 B · 8 bitsType 안에서 세부 상태를 구분합니다. Type과 함께 해석해야 합니다.
  • Type 3, Code 0 — 네트워크에 도달할 수 없음
  • Type 3, Code 1 — 호스트에 도달할 수 없음
  • Type 3, Code 3 — 포트에 도달할 수 없음
  • Type 3, Code 4 — 단편화 필요, DF 설정됨
  • Type 11, Code 0 / 1 — TTL 초과 / 조각 재조립 시간 초과
  • Type 5, Code 1 — 호스트 Redirect
  • Type 12, Code 0 — 헤더 문제; Pointer로 위치 표시
  • Type 0 / 8, Code 0 — Echo 응답 / 요청
ChecksumChecksum2 B · 16 bitsICMP 메시지 전체를 검사하며 바깥쪽 IPv4 헤더는 제외합니다. 오류 메시지에 인용된 원래 IPv4 헤더와 데이터는 ICMP 메시지의 일부이므로 포함합니다.
Type-specific FieldsType-specific Message Fields표시한 오류·Echo 형식: 4 B · 32 bits표시한 오류·Echo 형식에서는 식별자·순서 번호, 다음 홉 MTU, 게이트웨이 주소, 포인터 등의 의미로 사용됩니다. 모든 ICMP 확장 유형의 고정 길이를 뜻하지 않습니다.
IdentifierIdentifier2 B · 16 bitsEcho 요청과 응답을 대응시키는 식별자입니다.
Sequence NumberSequence Number2 B · 16 bits연속된 Echo 요청을 구별하는 순서 번호입니다.
DataMessage Data가변 길이Echo 응답은 요청의 데이터를 돌려줍니다. 오류 메시지는 원인이 된 패킷의 일부를 포함합니다.
Next-Hop MTUNext-Hop Maximum Transmission Unit2 B · 16 bitsType 3, Code 4에서 다음 홉 링크의 MTU를 바이트로 알립니다. 옛 형식에서는 0일 수 있습니다.
Gateway AddressGateway Internet Address4 B · 32 bitsRedirect가 안내하는 다음 홉 라우터의 IPv4 주소입니다.
PointerPointer1 B · 8 bits표시한 Type 12, Code 0에서 원래 IPv4 헤더의 문제 바이트를 가리킵니다.
UnusedUnused형식별 2 / 3 / 4 B표시한 기본 형식에서는 0으로 보냅니다. 확장 형식은 예약 영역 일부를 다른 용도로 사용할 수 있습니다.

오류·Redirect의 인용 영역에는 원래 IPv4 헤더와 데이터 앞부분이 들어갑니다. RFC792 기본 형식은 데이터의 첫 8 B를 인용하며 더 많은 데이터를 포함하는 후속 규격과 RFC4884 확장도 있습니다. 여기서는 확장 없는 기본 형식을 표시합니다.
