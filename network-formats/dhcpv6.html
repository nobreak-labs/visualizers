DHCPv6 Message

DHCPv6 일반 메시지, 릴레이 메시지와 옵션의 구조를 살펴보세요.

APPLICATION LAYER

DHCPv6 메시지 형식

한 행 32비트 · 비트 / 바이트 오프셋
필드 이름과 역할
필드풀네임크기설명
msg-typeMessage Type1 B · 8 bits메시지 동작을 식별합니다. 아래는 기본 메시지 유형이며, 확장 유형은 IANA에 별도로 등록됩니다. 12와 13은 릴레이 형식을 사용합니다.
  • 1 — SOLICIT
  • 2 — ADVERTISE
  • 3 — REQUEST
  • 4 — CONFIRM
  • 5 — RENEW
  • 6 — REBIND
  • 7 — REPLY
  • 8 — RELEASE
  • 9 — DECLINE
  • 10 — RECONFIGURE
  • 11 — INFORMATION-REQUEST
  • 12 — RELAY-FORW
  • 13 — RELAY-REPL
transaction-idTransaction Identifier3 B · 24 bits클라이언트와 서버 간 요청·응답을 대응시키는 식별자입니다. 서버가 먼저 보내는 RECONFIGURE 메시지에서는 0입니다.
hop-countRelay Hop Count1 B · 8 bitsRELAY-FORW에서는 이전에 메시지를 전달한 릴레이 수입니다. 최초 릴레이는 0으로 설정하며, RELAY-REPL에서는 요청의 값을 복사합니다.
link-addressLink Address16 B · 128 bits서버가 클라이언트의 링크를 식별하는 데 사용할 수 있는 IPv6 주소입니다. 링크 식별을 다른 정보에 의존하는 경우 등에는 ::로 설정할 수 있습니다.
peer-addressPeer Address16 B · 128 bits릴레이가 메시지를 받은 클라이언트 또는 이전 릴레이의 IPv6 주소입니다.
option-codeOption Code2 B · 16 bits옵션 유형을 식별합니다.
  • 1 — Client Identifier — 클라이언트 DUID
  • 2 — Server Identifier — 서버 DUID
  • 3 — IA_NA — 비임시 주소 연관 정보
  • 5 — IAADDR — IPv6 주소
  • 6 — Option Request Option
  • 9 — Relay Message
  • 13 — Status Code
  • 14 — Rapid Commit
  • 23 — DNS Recursive Name Server
  • 24 — Domain Search List
  • 25 — IA_PD — 프리픽스 위임
  • 26 — IAPREFIX — 위임 프리픽스
option-lenOption Data Length2 B · 16 bitsoption-data의 바이트 길이입니다. 코드와 길이 자체의 4바이트는 포함하지 않습니다.
option-dataOption Data가변 길이옵션별 데이터입니다. 릴레이 메시지는 Relay Message 옵션에 원래 DHCPv6 메시지를 넣습니다.
DUIDDHCP Unique Identifier가변 길이Client Identifier와 Server Identifier 옵션에 담기는 지속적인 식별자입니다.
  • 1 — DUID-LLT — 링크 계층 주소와 시간
  • 2 — DUID-EN — 기업 번호 기반
  • 3 — DUID-LL — 링크 계층 주소
  • 4 — DUID-UUID — UUID 기반
