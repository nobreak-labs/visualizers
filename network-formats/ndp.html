NDP

ICMPv6 기반 NDP의 다섯 가지 기본 메시지와 링크 계층 주소 옵션입니다.

IPV6 CONTROL

NDP 메시지 형식

한 행 32비트 · 비트 / 바이트 오프셋
필드 이름과 역할
필드풀네임크기설명
TypeICMPv6 Message Type1 B · 8 bitsNDP는 ICMPv6의 다음 메시지 유형을 사용합니다.
  • 133 — Router Solicitation (RS) — 라우터 정보 요청
  • 134 — Router Advertisement (RA) — 라우터·프리픽스 정보 광고
  • 135 — Neighbor Solicitation (NS) — 이웃 주소·도달성 확인
  • 136 — Neighbor Advertisement (NA) — 이웃 정보 광고
  • 137 — Redirect — 더 적절한 다음 홉 안내
CodeICMPv6 Message Code1 B · 8 bits여기에 표시한 NDP 메시지에서는 0입니다.
ChecksumICMPv6 Checksum2 B · 16 bitsIPv6 의사 헤더와 ICMPv6 메시지를 포함하는 체크섬입니다.
ReservedReserved4 B · 32 bits송신 시 0으로 채우는 예약 영역입니다.
Target AddressTarget IPv6 Address16 B · 128 bitsNS·NA가 조회하거나 광고하는 IPv6 주소입니다. Redirect에서는 다음 홉 주소를 나타냅니다.
Cur Hop LimitCurrent Hop Limit1 B · 8 bits호스트에 권고하는 홉 한도입니다. 0은 권고하지 않음을 뜻합니다.
MManaged Address Configuration Flag1 bit1이면 DHCPv6 주소 설정 정보를 사용할 수 있음을 나타냅니다.
OOther Configuration Flag1 bit1이면 DHCPv6로 주소 이외의 설정 정보를 얻을 수 있음을 나타냅니다.
RA 확장/예약Extension Flags / Reserved6 bitsRFC4861에서 예약했던 영역으로, IANA 등록에 따라 H(1비트, Home Agent), Prf(2비트, 라우터 선호도), P(1비트, ND Proxy), S(1비트, SNAC Router)와 예약 1비트를 포함합니다. RA의 S와 NA의 Solicited S는 서로 다른 플래그입니다. Prf 값은 00=중간, 01=높음, 11=낮음이며 10은 예약입니다. SNAC 비트의 문서 상태는 IANA 등록을 참고합니다.
Router LifetimeRouter Lifetime2 B · 16 bits기본 라우터로 사용할 수 있는 시간(초)입니다. 0은 기본 라우터가 아님을 뜻합니다.
Reachable TimeReachable Time4 B · 32 bits이웃을 도달 가능한 상태로 취급하는 시간(밀리초)입니다. 0은 미지정입니다.
Retrans TimerRetransmission Timer4 B · 32 bitsNS 재전송 간격(밀리초)입니다. 0은 미지정입니다.
RRouter Flag1 bit송신자가 라우터이면 1입니다.
SSolicited Flag1 bitNS 송신자에게 유니캐스트로 응답하는 NA에서 1입니다. 멀티캐스트 NA와 비요청 NA에서는 0입니다. DAD의 출발지 ::인 NS에 응답할 때도 멀티캐스트로 보내므로 0입니다.
OOverride Flag1 bit캐시의 링크 계층 주소를 덮어쓸 수 있음을 나타냅니다.
NA ReservedReserved29 bits송신 시 0으로 채우는 예약 비트입니다.
Destination AddressDestination IPv6 Address16 B · 128 bitsRedirect가 적용되는 원래 패킷의 목적지 IPv6 주소입니다.
OptionsNeighbor Discovery Options가변 길이Type(1 B), Length(1 B), 옵션 데이터로 구성됩니다. Length는 옵션 전체 길이를 8바이트 단위로 표시하며 0은 허용되지 않습니다.
  • 1 — Source Link-Layer Address
  • 2 — Target Link-Layer Address
  • 3 — Prefix Information
  • 4 — Redirected Header
  • 5 — MTU
Option TypeOption Type1 B · 8 bitsNDP 옵션 유형입니다.
  • 1 — Source Link-Layer Address
  • 2 — Target Link-Layer Address
  • 3 — Prefix Information
  • 4 — Redirected Header
  • 5 — MTU
Option LengthOption Length1 B · 8 bits옵션 전체 크기를 8바이트 단위로 표시합니다. Ethernet 주소 옵션은 1입니다.
Link-Layer AddressLink-Layer Address6 B · 48 bitsEthernet에서 사용하는 6바이트 MAC 주소입니다.

이 도표의 고정 길이는 ICMPv6 Type부터 계산하며 IPv6 헤더와 옵션은 제외합니다. 모든 NDP 메시지의 바깥쪽 IPv6 Hop Limit은 255여야 합니다. RA의 Cur Hop Limit은 호스트에 권고하는 별도 값입니다.
