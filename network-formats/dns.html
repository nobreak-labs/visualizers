DNS Message

DNS 공통 헤더, 플래그와 네 개의 메시지 영역을 살펴보세요.

APPLICATION LAYER

DNS 메시지

한 행 32비트 · 비트 / 바이트 오프셋
QuestionQNAME (가변) → QTYPE (2 B · 16 bits) → QCLASS (2 B · 16 bits)
Resource Record · Answer / Authority / AdditionalNAME (가변) → TYPE (2 B) → CLASS (2 B) → TTL (4 B) → RDLENGTH (2 B) → RDATA (가변)
필드 이름과 역할
필드풀네임크기설명
IDTransaction Identifier2 B · 16 bits질의와 응답을 대응시키는 거래 식별자입니다.
FlagsMessage Flags2 B · 16 bits질의·응답 구분, 처리 방식 및 응답 상태를 담습니다. 헤더 첫 행의 뒤쪽 16비트에 세부 필드를 표시합니다.
QDCOUNTQuestion Count2 B · 16 bits일반 QUERY의 Question 영역 항목 수입니다. OPCODE=0에서는 0 또는 1만 허용하며, 1보다 크면 FORMERR로 처리합니다.
ANCOUNTAnswer Record Count2 B · 16 bitsAnswer 영역의 리소스 레코드 개수입니다.
NSCOUNTAuthority Record Count2 B · 16 bitsAuthority 영역의 리소스 레코드 개수입니다.
ARCOUNTAdditional Record Count2 B · 16 bitsAdditional 영역의 리소스 레코드 개수입니다.
QRQuery / Response1 bit메시지가 질의인지 응답인지 표시합니다.
  • 0 — 질의
  • 1 — 응답
OPCODEOperation Code4 bits메시지 동작을 식별합니다. 아래 영역명과 COUNT 설명은 일반 QUERY 기준이며, UPDATE·DSO는 영역의 의미나 후속 형식이 다릅니다.
  • 0 — QUERY — 일반 질의
  • 4 — NOTIFY — 변경 통지
  • 5 — UPDATE — 동적 갱신
AAAuthoritative Answer1 bit응답에서 서버가 질의 이름의 권한 서버임을 나타냅니다. 여러 이름이 있으면 질의 이름 또는 Answer의 첫 소유자 이름을 기준으로 해석합니다.
TCTruncated1 bit메시지가 잘렸음을 나타냅니다.
RDRecursion Desired1 bit클라이언트가 재귀 질의를 요청합니다.
RARecursion Available1 bit서버가 재귀 질의를 제공함을 나타냅니다.
ZReserved1 bit예약 비트로 0입니다.
ADAuthentic Data1 bit응답에서는 리졸버가 Answer·Authority의 모든 RRset을 authentic하다고 판단했음을 나타냅니다. Additional 전체의 검증을 보장하지 않습니다. 질의에서는 AD 의미를 이해하고 응답의 AD 값에 관심이 있음을 표시합니다.
CDChecking Disabled1 bit클라이언트가 DNSSEC 검증을 비활성화하도록 요청합니다.
RCODEResponse Code4 bits기본 응답 상태 코드입니다. EDNS는 이를 확장할 수 있습니다.
  • 0 — NOERROR — 오류 없음
  • 1 — FORMERR — 형식 오류
  • 2 — SERVFAIL — 서버 처리 실패
  • 3 — NXDOMAIN — 이름 없음
  • 4 — NOTIMP — 미구현
  • 5 — REFUSED — 처리 거부
QuestionQuestion Section가변 길이QNAME, QTYPE, QCLASS로 이루어진 질의 영역입니다.
QNAMEQuestion Name가변 길이비압축 도메인 이름은 길이 바이트와 라벨들로 표현하고 루트의 길이 0 바이트로 끝납니다. 라벨은 최대 63바이트이며 비압축 이름 전체는 길이 바이트와 마지막 0을 포함해 최대 255바이트입니다. 압축하면 이름 전체 또는 뒤쪽 부분을 메시지 내 이전 이름에 대한 포인터로 대체하며, 해당 인코딩은 포인터로 끝납니다.
QTYPE / TYPEQuestion Type / Resource Record Type2 B · 16 bitsQTYPE은 질의 유형이고 TYPE은 반환하는 리소스 레코드 유형입니다. 아래에는 일반적인 레코드 유형을 표시합니다.
  • 1 — A — IPv4 주소
  • 2 — NS — 권한 서버
  • 5 — CNAME — 별칭
  • 6 — SOA — 영역 관리 정보
  • 12 — PTR — 역방향 이름
  • 15 — MX — 메일 교환 서버
  • 16 — TXT — 텍스트
  • 28 — AAAA — IPv6 주소
  • 33 — SRV — 서비스 위치
  • 65 — HTTPS — HTTPS 서비스 바인딩
QCLASS / CLASSQuestion Class / Resource Record Class2 B · 16 bits질의·레코드의 클래스입니다. 일반적인 인터넷 DNS의 IN 클래스를 표시합니다.
  • 1 — IN — Internet
AnswerAnswer Section가변 길이질의에 대한 답을 담는 리소스 레코드 영역입니다.
AuthorityAuthority Section가변 길이권한 서버 관련 리소스 레코드 영역입니다.
AdditionalAdditional Section가변 길이추가 정보를 담는 리소스 레코드 영역입니다. EDNS의 OPT도 이 영역에 놓입니다.
NAMEResource Record Name가변 길이리소스 레코드가 적용되는 도메인 이름입니다.
TTLTime to Live4 B · 32 bits일반 RR을 캐시에 보관할 수 있는 최대 시간(초)입니다. 필드는 32비트지만 유효 범위는 0–2^31−1이며, 최상위 비트가 1인 수신 값은 0으로 취급합니다. EDNS의 OPT 의사 레코드는 이 위치를 TTL 대신 확장 RCODE·버전·플래그에 사용합니다.
RDLENGTHResource Data Length2 B · 16 bitsRDATA의 바이트 길이입니다.
RDATAResource Data가변 길이TYPE에 따른 실제 레코드 데이터입니다.

이 도표는 일반 DNS 질의·응답의 메시지 구조입니다. TCP 전송에서는 DNS 메시지 앞에 2바이트 길이 필드가 붙으며, 이 필드는 12바이트 DNS 헤더에 포함되지 않습니다.
