필드 이름과 역할
필드풀네임크기설명
TypeMessage Type1 B · 8 bits메시지 유형입니다. 주요 값은 다음과 같습니다.
  • 1 — Destination Unreachable
  • 2 — Packet Too Big
  • 3 — Time Exceeded
  • 4 — Parameter Problem
  • 128 — Echo Request
  • 129 — Echo Reply
  • 133–137 — NDP 메시지
CodeMessage Code1 B · 8 bitsType 안에서 세부 상태를 구분합니다. Type과 함께 해석해야 합니다.
  • Type 1, Code 0 — 목적지로 가는 경로 없음
  • Type 1, Code 1 — 관리 정책으로 금지
  • Type 1, Code 4 — 목적지 포트에 도달할 수 없음
  • Type 2, Code 0 — Packet Too Big
  • Type 3, Code 0 / 1 — 홉 한도 초과 / 조각 재조립 시간 초과
  • Type 4, Code 0 / 1 / 2 — 잘못된 헤더 필드 / 알 수 없는 Next Header / 알 수 없는 옵션
  • Type 128 / 129, Code 0 — Echo 요청 / 응답
ChecksumChecksum2 B · 16 bits메시지 전체를 검사합니다. IPv6 의사 헤더도 계산에 포함합니다.
Type-specific FieldsType-specific Message Fields유형별 상이 · 기본 오류·Echo는 4 BRFC4443의 기본 오류·Echo 형식에서는 4바이트에 식별자·순서 번호, MTU, 포인터 등을 담습니다. NDP 등 다른 유형의 고정 필드는 길이가 다릅니다.
IdentifierIdentifier2 B · 16 bitsEcho 요청과 응답을 대응시키는 식별자입니다.
Sequence NumberSequence Number2 B · 16 bits연속된 Echo 요청을 구별하는 순서 번호입니다.
DataMessage Data가변 길이Echo 응답은 요청의 데이터를 돌려줍니다. 오류 메시지는 원인이 된 패킷의 일부를 포함합니다.
MTUMaximum Transmission Unit4 B · 32 bitsPacket Too Big에서 전달할 수 없는 다음 링크의 MTU를 바이트로 알립니다.
PointerPointer4 B · 32 bits원래 IPv6 패킷 시작부터 문제 위치까지의 바이트 오프셋입니다.
UnusedUnused4 B · 32 bits표시한 기본 Destination Unreachable·Time Exceeded 형식에서 0으로 보냅니다.

오류 메시지는 원래 IPv6 패킷을 가능한 한 많이 인용하되, 오류 메시지를 담는 IPv6 패킷 전체가 최소 IPv6 MTU인 1280 B를 넘지 않도록 합니다. 여기서는 RFC4443의 기본 오류 형식을 표시하며, NDP 메시지는 별도 화면에서 볼 수 있습니다.
