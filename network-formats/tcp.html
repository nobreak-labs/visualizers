TRANSPORT LAYER

TCP 세그먼트 헤더

한 행 32비트 · 비트 / 바이트 오프셋
필드 이름과 역할
필드풀네임크기설명
Source PortSource Port2 B · 16 bits송신 애플리케이션의 포트입니다.
Destination PortDestination Port2 B · 16 bits수신 애플리케이션의 포트입니다.
  • 22 — SSH
  • 25 — SMTP
  • 53 — DNS
  • 80 — HTTP
  • 443 — HTTPS
Sequence NumberSequence Number4 B · 32 bits이 세그먼트의 첫 데이터 바이트 순서 번호입니다. SYN은 초기 순서 번호를 담고 순서 공간을 하나 사용합니다.
Acknowledgment NumberAcknowledgment Number4 B · 32 bits다음에 받기를 기대하는 순서 번호입니다. ACK가 1일 때 유효합니다.
OffsetData Offset4 bitsTCP 헤더 길이를 4바이트 단위로 표시합니다.
  • 5 — 20 B — 옵션 없음
  • 6–15 — 24–60 B — 옵션 포함
ReservedReserved3 bits미래 확장을 위해 예약된 세 비트입니다. 송신 시 0입니다.
AEAccurate ECN1 bitRFC9768에서 과거 NS 위치에 할당한 Accurate ECN 비트입니다. AccECN을 협상한 연결에서는 AE·CWR·ECE를 묶어 3비트 ACE 피드백 필드로 사용합니다.
CWRCongestion Window Reduced1 bit기존 ECN 방식에서 혼잡 윈도를 줄였음을 알립니다.
ECEECN Echo1 bit기존 ECN 방식에서 ECN 지원 또는 혼잡 경험을 알립니다.
URGUrgent1 bitUrgent Pointer가 유효함을 나타냅니다.
ACKAcknowledgment1 bitAcknowledgment Number가 유효함을 나타냅니다.
PSHPush1 bit수신 측에 버퍼의 데이터를 애플리케이션으로 전달하도록 요청합니다.
RSTReset1 bit연결을 초기화하거나 거부합니다.
SYNSynchronize1 bit연결 시작 시 순서 번호를 동기화합니다.
FINFinish1 bit송신 측에 더 보낼 데이터가 없음을 뜻합니다. 순서 공간을 하나 사용합니다.
WindowReceive Window2 B · 16 bits이 세그먼트를 보낸 측이 ACK 번호부터 수신할 수 있는 데이터 양을 바이트 단위로 알립니다. Window Scale 협상 후 배율을 적용하지만, SYN이 설정된 세그먼트의 Window 값에는 적용하지 않습니다.
ChecksumTCP Checksum2 B · 16 bitsIP 의사 헤더, TCP 헤더와 데이터를 검사하는 필수 체크섬입니다.
Urgent PointerUrgent Pointer2 B · 16 bitsSequence Number 기준 긴급 데이터의 끝 다음 위치를 나타냅니다. URG가 1일 때 유효합니다.
Options + PaddingTCP Options and Padding0–40 B · 0–320 bits선택적 헤더 필드이며 헤더를 4바이트 배수로 맞춥니다.
  • 0 — End of Option List
  • 1 — No Operation
  • 2 — Maximum Segment Size (MSS)
  • 3 — Window Scale
  • 4 — SACK Permitted
  • 5 — Selective Acknowledgment (SACK)
  • 8 — Timestamps
DataApplication Data가변 길이TCP가 운반하는 바이트 스트림의 일부입니다. 데이터 시작 위치는 Data Offset × 4 B입니다.
