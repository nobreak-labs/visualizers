Ethernet II Frame

전송 순서에 따라 물리 계층 구간과 Ethernet II 프레임의 필드를 살펴보세요.

LINK LAYER

Ethernet II 프레임

전송 순서 · 필드 길이
필드 이름과 역할
필드풀네임크기설명
PreamblePreamble7 B수신기가 송신 신호에 동기화하도록 하는 반복 패턴입니다.
SFDStart Frame Delimiter1 B프리앰블의 끝과 프레임 시작을 표시합니다.
DstDestination Media Access Control Address6 B프레임을 받을 장치의 MAC 주소입니다.
SrcSource Media Access Control Address6 B프레임을 보낸 장치의 MAC 주소입니다.
TagIEEE 802.1Q VLAN Tag4 B출발지 MAC과 EtherType 사이에 삽입되는 VLAN 태그입니다.
TypeEtherType2 B페이로드에 담긴 프로토콜을 식별합니다. 주요 값은 다음과 같습니다.
  • 0x0800 — IPv4
  • 0x0806 — ARP
  • 0x86DD — IPv6
  • 0x88CC — LLDP — 링크 계층 이웃 탐색
Payload + PaddingPayload and Padding46–1500 B / 42–1500 B상위 계층 데이터를 담습니다. 태그 유무에 따라 최소 크기가 다르며, 부족한 길이는 패딩으로 채웁니다. MTU는 최대 데이터 크기인 1500 B입니다.
FCSFrame Check Sequence4 B프레임 끝에 위치하는 트레일러 필드로, MAC 헤더와 데이터의 오류를 검출하는 CRC-32 값입니다.
IPGInterpacket Gap96 bit times다음 전송 전의 유휴 시간으로, 12바이트를 전송하는 시간에 해당합니다.
TPIDTag Protocol Identifier16 bits802.1Q 태그를 식별하는 값이며 0x8100입니다.
TCITag Control Information16 bitsPCP, DEI, VID를 포함하는 태그 제어 정보입니다.
PCPPriority Code Point3 bits트래픽 우선순위를 나타냅니다.
DEIDrop Eligible Indicator1 bit혼잡 시 폐기 대상으로 취급할 수 있는 프레임을 표시합니다.
VIDVLAN Identifier12 bits프레임이 속한 VLAN을 식별합니다. 1–4094는 VLAN ID, 0은 VLAN ID를 지정하지 않는 우선순위 태그이며 4095는 예약 값입니다.

길이는 일반적인 1500바이트 MTU와 단일 802.1Q C-태그 기준입니다. 프레임 길이에는 Dst부터 FCS까지 포함하며, Preamble·SFD·IPG는 제외합니다. 태그가 있어도 최소 프레임 길이는 64바이트이며, 기존 패딩을 유지해 태그를 삽입하면 68바이트가 될 수도 있습니다.
