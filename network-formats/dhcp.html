DHCPv4 Message

DHCPv4의 고정 필드와 주소, 큰 필드 및 확장 영역을 살펴보세요.

APPLICATION LAYER

DHCPv4 메시지 형식

한 행 32비트 · 비트 / 바이트 오프셋
필드 이름과 역할
필드풀네임크기설명
opOperation1 B · 8 bits요청과 응답을 구분합니다. DHCP 메시지 유형 옵션과는 별개입니다.
  • 1 — BOOTREQUEST — 클라이언트 요청
  • 2 — BOOTREPLY — 서버 응답
htypeHardware Type1 B · 8 bits하드웨어 주소 유형입니다. 이 도표는 Ethernet 기준입니다.
  • 1 — Ethernet
hlenHardware Address Length1 B · 8 bits하드웨어 주소 길이(바이트)입니다. Ethernet MAC 주소는 6입니다.
hopsRelay Hop Count1 B · 8 bits클라이언트는 0으로 시작하며 중계 에이전트가 전달할 때 증가시킵니다.
xidTransaction Identifier4 B · 32 bits클라이언트 요청과 서버 응답을 대응시키는 거래 식별자입니다.
secsSeconds Elapsed2 B · 16 bits주소 획득 또는 갱신을 시작한 뒤 경과한 초입니다.
flagsBroadcast Flag and Reserved Bits2 B · 16 bits최상위 B 비트는 클라이언트가 주소 설정 전 유니캐스트 IPv4 패킷을 받을 수 없어 브로드캐스트 응답을 요청함을 나타냅니다. 나머지 15비트는 송신 시 0으로 채우는 예약 비트입니다.
  • 0x0000 — Broadcast = 0
  • 0x8000 — Broadcast = 1
ciaddrClient IP Address4 B · 32 bits클라이언트가 이미 설정한 IPv4 주소입니다. BOUND·RENEWING·REBINDING 상태에서 사용하며, 초기 주소 획득에서는 0입니다.
yiaddrYour IP Address4 B · 32 bits서버가 클라이언트에게 제공하는 IPv4 주소입니다.
siaddrNext Server IP Address4 B · 32 bits다음 부트스트랩 단계에서 사용할 서버 IPv4 주소입니다. DHCP Server Identifier 옵션과 별개의 값입니다.
giaddrRelay Agent IP Address4 B · 32 bits중계 에이전트의 IPv4 주소입니다.
chaddrClient Hardware Address16 B · 128 bits클라이언트의 하드웨어 주소를 담는 16바이트 영역입니다. Ethernet에서는 앞 6바이트가 MAC 주소입니다.
snameServer Host Name64 B · 512 bits선택적 서버 호스트 이름을 담는 고정 64바이트 영역입니다. 이름 문자열은 NUL로 종료하며, Option Overload가 지정되면 옵션 영역으로 사용합니다.
fileBoot File Name128 B · 1024 bits부팅 파일 이름을 담는 고정 128바이트 영역입니다. 이름 문자열은 NUL로 종료하며, Option Overload가 지정되면 옵션 영역으로 사용합니다.
Magic CookieDHCP Magic Cookie4 B · 32 bitsDHCP 옵션을 식별하는 고정 값입니다.
  • 0x63825363 — 십진 바이트 값 99, 130, 83, 99
OptionsDHCP Options가변 길이일반 옵션은 Code(1 B), Length(1 B), Data로 구성됩니다. Pad(0)와 End(255)는 Code 한 바이트만 사용합니다.
  • 1 — Subnet Mask
  • 3 — Router
  • 6 — DNS Servers
  • 12 — Host Name
  • 50 — Requested IP Address
  • 51 — IP Address Lease Time
  • 52 — Option Overload
  • 53 — DHCP Message Type
  • 54 — Server Identifier
  • 55 — Parameter Request List
  • 58 / 59 — Renewal (T1) / Rebinding (T2) Time
  • 61 — Client Identifier
  • 255 — End
Option 53DHCP Message Type Option3 B · 24 bits옵션 형식은 Code 53, Length 1, 메시지 유형 1바이트입니다.
  • 1 — DHCPDISCOVER
  • 2 — DHCPOFFER
  • 3 — DHCPREQUEST
  • 4 — DHCPDECLINE
  • 5 — DHCPACK
  • 6 — DHCPNAK
  • 7 — DHCPRELEASE
  • 8 — DHCPINFORM
CodeOption Code1 B · 8 bitsDHCP 옵션 식별 코드입니다.
LengthOption Data Length1 B · 8 bits뒤따르는 옵션 데이터의 바이트 길이입니다.
