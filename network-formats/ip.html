IPv4 Packet

IPv4 헤더의 비트 배치와 길이, 단편화 제어 및 프로토콜 값을 살펴보세요.

NETWORK LAYER

IPv4 헤더

한 행 32비트 · 비트 / 바이트 오프셋
필드 이름과 역할
필드풀네임크기설명
VersionInternet Protocol Version4 bitsIPv4에서는 값이 4입니다.
IHLInternet Header Length4 bits헤더 길이를 4바이트 단위로 표시합니다.
  • 5 — 20 B — 옵션 없음
  • 6–15 — 24–60 B — 옵션 포함
DSCPDifferentiated Services Code Point6 bits서비스 등급을 식별합니다. 주요 값은 다음과 같습니다.
  • 0 — CS0 / 기본 전달
  • 34 — AF41
  • 46 — EF — 신속 전달
  • 48 — CS6 — 네트워크 제어
ECNExplicit Congestion Notification2 bits혼잡 통지를 나타냅니다.
  • 0 (00) — Not-ECT — ECN 미지원
  • 1 (01) — ECT(1) — ECN 사용 가능
  • 2 (10) — ECT(0) — ECN 사용 가능
  • 3 (11) — CE — 혼잡 경험
Total LengthTotal Length2 B · 16 bitsIPv4 헤더와 데이터를 합한 전체 바이트 길이입니다. 최대 65,535 B입니다.
IdentificationIdentification2 B · 16 bits단편화·재조립에서 같은 데이터그램의 조각을 식별합니다. DF=1, MF=0, Fragment Offset=0인 atomic 데이터그램에서는 의미가 없으며 수신자는 무시합니다.
FlagsFragmentation Flags3 bits단편화 제어 비트입니다.
  • Reserved — 예약 비트, 0
  • DF — Don’t Fragment — 단편화 금지
  • MF — More Fragments — 뒤에 조각이 더 있음
Fragment OffsetFragment Offset13 bits원본 데이터에서 이 조각의 위치를 8바이트 단위로 표시합니다.
TTLTime to Live1 B · 8 bits라우터를 거칠 때 감소하며 0이 되면 패킷을 폐기합니다.
ProtocolProtocol1 B · 8 bits데이터에 담긴 다음 프로토콜을 식별합니다.
  • 1 — ICMP
  • 6 — TCP
  • 17 — UDP
  • 47 — GRE
  • 50 — ESP
  • 89 — OSPF
Header ChecksumHeader Checksum2 B · 16 bitsIPv4 헤더만 검사하는 16비트 체크섬입니다.
Source AddressSource IPv4 Address4 B · 32 bits송신자의 IPv4 주소입니다.
Destination AddressDestination IPv4 Address4 B · 32 bits수신자의 IPv4 주소입니다.
Options + PaddingOptions and Padding0–40 B · 0–320 bits선택적 헤더 정보입니다. 헤더 전체를 4바이트 배수로 맞춥니다.
  • 0 — End of Option List
  • 1 — No Operation
DataPayload가변 길이상위 프로토콜의 헤더와 데이터를 담습니다. 헤더 뒤에서 시작합니다.
