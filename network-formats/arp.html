ARP Message

Ethernet에서 IPv4 주소를 MAC 주소로 찾을 때 쓰는 ARP 형식입니다.

L2 / L3 ADDRESS RESOLUTION

ARP 메시지

Ethernet / IPv4 예시
필드 이름과 역할
필드풀네임크기설명
HTYPEHardware Type2 B링크 계층의 하드웨어 유형입니다. 이 도표는 Ethernet 기준입니다.
  • 1 (0x0001) — Ethernet
PTYPEProtocol Type2 B주소를 찾을 네트워크 계층 프로토콜을 식별하며 EtherType과 같은 번호 체계를 사용합니다.
  • 0x0800 — IPv4 — Ethernet에서 사용하는 일반적인 ARP 값

이 도표는 IPv4(0x0800) 기준입니다. Ethernet 헤더에서 ARP를 식별하는 0x0806은 이 필드의 IPv4 값과 구분해야 합니다.

HLENHardware Length1 B하드웨어 주소 하나의 바이트 길이입니다. Ethernet MAC 주소는 6 B이므로 값은 6입니다.
PLENProtocol Length1 B프로토콜 주소 하나의 바이트 길이입니다. IPv4 주소는 4 B이므로 값은 4입니다.
OPEROperation2 B수행할 동작을 나타냅니다. 이 도표의 ARP는 요청(1)과 응답(2)을 사용합니다.
  • 1 (0x0001) — ARP Request — 주소 해석 요청
  • 2 (0x0002) — ARP Reply — 주소 해석 응답
SHASender Hardware Address6 B · HLEN송신자의 MAC 주소입니다. 응답에서는 조회한 IPv4 주소에 대응하는 MAC 주소를 담습니다.
SPASender Protocol Address4 B · PLEN송신자의 IPv4 주소입니다.
THATarget Hardware Address6 B · HLEN대상의 MAC 주소입니다. 요청에서는 아직 모르는 주소로 일반적으로 0으로 채우고 수신 시 무시하며, 응답에서는 요청자의 MAC 주소를 담습니다.
TPATarget Protocol Address4 B · PLEN대상의 IPv4 주소입니다. 요청에서는 MAC 주소를 찾으려는 IPv4 주소를 담습니다.

ARP는 IPv4 주소에 대응하는 MAC 주소를 찾는 주소 해석 프로토콜입니다. Ethernet 프레임으로 직접 전달되며, L3 주소와 L2 주소를 연결합니다. 계층 분류는 자료에 따라 다르므로 여기서는 두 계층 사이의 주소 해석 기능으로 표시합니다.
